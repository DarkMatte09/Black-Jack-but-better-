### ✨ Features

- 🪙 **Coin Flip Gamble** — Test your luck right at startup. 50/50 shot to enter or get booted.
- 💰 **Persistent Bankroll** — Your balance saves automatically across sessions (`$1,000` starting bank).
- 📊 **Detailed History & Streaks** — Tracks win/loss streaks, personal bests, and full game logs.
- 🃏 **Classic & Dynamic Rules** — Standard dealer logic, split-second decisions, terminal clears for clean UI.
- 🔮 **Hidden Secrets** — 1% rare easter egg clutch saves when all hope is lost.

---

### ⚡ Quickstart

Clone the repository and run immediately:

```bash
# Clone
git clone https://github.com/DarkMatte09/Black-Jack-but-better-.git

# Navigate
cd Black-Jack-but-better-

# Play
python main.py
```
